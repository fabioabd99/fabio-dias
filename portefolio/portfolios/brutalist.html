Sobre

[ 01 / 05 ]

Sou Web Developer com paixão por criar produtos digitais que funcionam — rápidos, acessíveis e bonitos. Passo o tempo entre o backend em PHP e Laravel, interfaces em React, e a magia que acontece quando uma API bem desenhada encontra uma UI fluida.

Acredito que código bom é código que outros conseguem ler. Que performance é uma feature. E que cada projeto é uma oportunidade para aprender algo novo. Estou sempre a explorar — seja uma stack nova, um padrão arquitetural, ou um detalhe de animação.

Quando não estou a programar, estou provavelmente a desenhar a próxima ideia num caderno ou a perder-me em documentação técnica até às tantas.
